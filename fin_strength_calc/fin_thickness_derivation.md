# PFHE Plain 핀 적정두께 계산식 유도

**대상**: 브레이징 알루미늄 판형핀 열교환기(BAHX/PFHE) Plain 핀
**하중**: 층간 차압(ΔP) + 설계온도(T)의 영향
**허용응력 기준**: ASME Sec. VIII Div.1 (Sec. II-D 허용응력 S(T))
**핀 재질**: AL 3003-O (SB-209, 브레이징 후 완전 어닐링 'O' temper — ALPEMA 5.13)

---

## 1. 배경

ALPEMA Standard(2024) 5.15.1은 핀을 "압력하중을 견디는 구조 부재"로 규정하고, 핀의
최대 허용 설계압력을 **계산 또는 파열시험**으로 결정하도록 요구하지만(5.15.1.1/5.15.1.2),
압력용기 코드에는 핀 계산식이 수록되어 있지 않으며 구체적 방법은 제조자 고유 기술로
위임되어 있다. 본 문서는 공개된 역학 원리로부터 Plain 핀의 적정두께 계산식을 유도한다.

> **주의**: 본 유도식은 예비 설계(사양 검토·견적 검증·역산) 용도이다. 실제 제작용
> 설계는 ALPEMA 5.15.1.1에 따라 **코드 당국의 승인을 받은 제조자 계산법 또는
> 파열시험**으로 확정되어야 한다.

## 2. 범위와 가정

1. Plain(평판형) 핀만 대상으로 한다. Serrated/Perforated 핀은 유효 단면 감소
   계수(천공률 φ 등)를 추가로 반영해야 하며 본 문서 범위 밖이다.
2. **압력하중만** 고려한다. 열응력(과도 운전, 스트림 간 온도차)은 두께로 흡수하는
   것이 아니라 ALPEMA 8.1의 운전 제한(±1 °C/min 등)으로 관리하는 항목이다.
   온도의 영향은 재료 물성 S(T), E(T)의 저하로만 반영한다.
3. 탄성 해석 기반. 재료는 O-temper 최소 물성(3003-O: Su ≥ 96.5 MPa, Sy ≥ 34.5 MPa).
4. 피로, 크리프(>204 °C), 부식 여유는 범위 밖(청정 극저온 서비스 전제).
5. 디스트리뷰터/헤더 영역은 제외하고 유효 전열부(finned region)의 반복 단위 셀만 본다.

## 3. 기하 정의와 기호

핀 채널 반복 단위 셀(피치 p) 단면:

```
   파팅시트(위)     ┌──────────────────────┐  ← t_ps
                    │   │        │         │
      핀 웹 →       │   │t       │    h    │
                    │   │        │         │
   파팅시트(아래)   └──────────────────────┘
                        |←  p  →|
```

| 기호 | 의미 | 단위 |
|---|---|---|
| p | 핀 피치 (= 1/n, n: 핀 밀도) | mm |
| t | 핀 두께 | mm |
| h | 핀 높이 (= 사이드바 높이) | mm |
| t_ps | 파팅시트 두께 | mm |
| ΔP_t | 핀 인장 유발 차압 (층 내부압 − 인접층 압력) | MPa |
| ΔP_c | 핀 압축 유발 차압 (인접층 압력 − 층 내부압) | MPa |
| S(T) | 설계온도 T에서의 ASME 허용응력 (3003-O) | MPa |
| E(T) | 설계온도 T에서의 탄성계수 | MPa |
| ν | 포아송비 (알루미늄 0.33) | — |

### 설계 차압의 선정

인접 층의 압력은 신뢰할 수 있는 감압 방지 수단이 없는 한 **0(대기압)으로 가정**하는
것이 코드 관행과 일치한다. 근거: ALPEMA 5.6의 압력시험은 "한 챔버에만" 시험압력을
가하며(단일 챔버 가압), 운전 중에도 인접 스트림의 블록인·감압·무유동(no-flow) 상태가
발생할 수 있다(ALPEMA 5.16). 따라서 기본 설계 기준:

$$\Delta P_t = \text{해당 층의 설계압력(MAWP)}, \qquad \Delta P_c = \text{인접층 설계압력(자층 감압 가정)}$$

## 4. 파손모드 1 — 핀 인장 (기본 사양 결정식)

### 4.1 하중 경로

층 내부압 ΔP_t 는 위·아래 파팅시트를 **벌리는 방향**으로 작용하고, 이 분리력은 파팅
시트에 브레이징된 핀 웹의 **인장**으로 지지된다(ALPEMA 5.15.1: "These loads essentially
produce tensile stresses in the fins").

### 4.2 유도

단위 유동길이(1 mm)와 한 피치(p)를 갖는 단위 셀에서 위쪽 파팅시트에 대한 힘 평형:

- 유체가 시트를 미는 면적: 개구폭 × 단위길이 = (p − t) × 1
  (핀 풋(fin foot)이 브레이징된 폭 t에는 유체압이 직접 작용하지 않음)
- 분리력: F = ΔP_t · (p − t)
- 이 힘을 받는 핀 웹 단면적: A = t × 1

핀 웹의 인장응력:

$$\sigma_t = \frac{\Delta P_t\,(p - t)}{t} \tag{1}$$

### 4.3 판정 기준과 두께식

1차 멤브레인 응력이므로 σ_t ≤ S(T):

$$\frac{\Delta P_t\,(p-t)}{t} \le S(T)
\;\;\Longrightarrow\;\;
\boxed{\,t \;\ge\; \frac{\Delta P_t \; p}{S(T) + \Delta P_t}\,} \tag{2}$$

식 (2)가 **차압·온도·피치로부터 Plain 핀 최소두께를 주는 기본 사양 결정식**이다.
온도는 S(T)의 감소를 통해 두께 증가로 반영된다.

보수적 변형(핀 풋 폭에도 전압력이 작용한다고 가정, 총피치 기준):

$$t \ge \frac{\Delta P_t\, p}{S(T)} \tag{2'}$$

식 (2)와 (2')의 차이는 ΔP ≪ S 인 통상 조건에서 수 % 이내다.

### 4.4 브레이즈 조인트에 대한 참고

핀-파팅시트 접합부의 유효폭은 필렛 때문에 핀 웹 두께 t보다 크므로, 접합부가 건전하다면
웹 단면이 지배한다. 접합 품질(보이드율)의 영향은 파열시험(5.15.1.2)의 안전계수가
포괄하는 영역이며, 필요시 식 (1)의 t에 접합 효율 계수를 곱해 반영할 수 있다.

## 5. 파손모드 2 — 핀 압축·좌굴 (외압/인접 고압 조건)

### 5.1 하중

자층이 감압(진공, 블록인)되고 인접층이 가압 상태이면 순 차압 ΔP_c 가 두 파팅시트를
**모으는 방향**으로 작용하여 핀 웹이 압축된다. 하중 경로는 4.2와 동일하므로:

$$\sigma_c = \frac{\Delta P_c\,(p - t)}{t} \tag{3}$$

### 5.2 좌굴 임계응력

Plain 핀 웹은 높이 h, 두께 t의 **긴 판 기둥**(유동 방향으로 연속)이다. 위·아래 가장자리는
파팅시트에 브레이징되어 회전 구속을 받는다. 단위폭 판의 굽힘강성
D = E t³ / [12(1 − ν²)] 을 갖는 기둥의 오일러 임계응력:

$$\sigma_{cr} = \frac{\pi^2\,E(T)}{12\,(1-\nu^2)}\left(\frac{t}{K\,h}\right)^{2} \tag{4}$$

- K: 유효길이계수. 이상적 양단 고정 0.5, 실무 권장 **K = 0.7**(브레이즈 구속 불완전성
  고려), 보수적으로 K = 1.0(양단 단순지지).

### 5.3 판정 기준

ASME Div.1 외압 좌굴 설계 철학(UG-28, 설계계수 ≈ 3)을 준용하여:

$$\sigma_c \;\le\; \min\!\left(\frac{\sigma_{cr}}{3},\; S(T)\right) \tag{5}$$

σ_cr /3 이 S(T)보다 크면(통상적인 짧고 두꺼운 핀) 재료 강도가 지배하며 식 (2)와 동일한
형태로 귀결된다. 얇고 높은 핀(t 작고 h 큰 경우)에서만 좌굴이 지배한다. 식 (3)과 (4)를
결합하면 t에 대한 3차식이 되므로 수치해(이분법)로 최소두께를 구한다(첨부 계산기 참조).

## 6. 파손모드 3 — 파팅시트 굽힘 연계

### 6.1 모델

파팅시트는 핀 풋들을 지지점으로 하는 **연속 스트립 보**로 거동한다. 시트 양면의 층간
순 차압 w = |P_A − P_B| 가 등분포 하중으로 작용하고, 지지 간격은 보수적으로 더 성긴
쪽 핀의 순 스팬을 취한다:

$$s = \max(p_A,\,p_B) - t_{fin}$$

양단 고정 스트립의 최대 모멘트(지지점): M = w s²/12, 단위폭 단면계수 Z = t_ps²/6.

$$\sigma_b = \frac{6M}{t_{ps}^2} = \frac{w\,s^2}{2\,t_{ps}^2} \tag{6}$$

### 6.2 판정 기준과 두께식

1차 굽힘응력 허용치 1.5 S(T) 적용(ASME 관행):

$$\sigma_b \le 1.5\,S(T)
\;\;\Longrightarrow\;\;
\boxed{\, t_{ps} \;\ge\; s\,\sqrt{\frac{w}{3\,S(T)}}\,} \tag{7}$$

**연계 의미**: 핀 피치 p를 키우면 식 (2)의 핀 두께와 식 (7)의 파팅시트 두께가 동시에
증가한다 — ALPEMA 5.15.2("파팅시트 응력은 인접층 압력하중과 사이드바 높이에 의존")와
정합. 반대면 핀이 인장 스테이로 작용하는 효과와 멤브레인 작용은 무시했으므로 식 (7)은
보수적이다.

## 7. 온도의 반영 — S(T), E(T)

### 7.1 허용응력 S(T): SB-209 3003-O, ASME Sec. II-D Table 1B (Div.1)

| 설계온도 | S (MPa) |
|---|---|
| ≤ 40 °C | 22.8 |
| 65 °C | 22.8 |
| 93 °C | 22.6 |
| 121 °C | 21.4 |
| 149 °C | 18.6 |
| 177 °C | 14.5 |
| 204 °C | 11.0 |

- 상온 값의 근거: min(Su/3.5, ⅔Sy) = min(96.5/3.5, ⅔×34.5) = min(27.6, **23.0**) → 항복 지배.
- 149 °C 이상은 시간 의존(크리프) 특성이 지배하기 시작하는 구간이다.
- 204 °C 는 ALPEMA Table 6-1의 3003 최대 적용 설계온도(ASME 기준)로, 이를 초과하는
  입력은 계산기에서 오류 처리한다.

> ⚠️ **위 표는 대표값이다. 실제 설계에는 적용 코드 연도판의 Sec. II-D 값을 확인하여
> 계산기 테이블을 교체할 것** (계산기의 `ALLOWABLE_S_TABLE` 또는 `--s-table` 옵션).

### 7.2 탄성계수 E(T): 알루미늄 (ASME Sec. II-D TM 계열)

| 온도 | E (GPa) |
|---|---|
| 25 °C | 68.9 |
| 93 °C | 66.2 |
| 149 °C | 63.4 |
| 204 °C | 60.0 |

중간 온도는 선형 보간한다. ν = 0.33.

## 8. 계산 절차 요약

1. 입력: ΔP_t, ΔP_c, 설계온도 T, 핀 피치 p, 핀 높이 h, (파팅시트용) 인접층 차압 w
2. S(T), E(T) 보간
3. **핀 인장 최소두께**: 식 (2) → t_min,t
4. **핀 좌굴 최소두께**: 식 (3)=(5) 수치해 → t_min,c
5. 요구 핀 두께 t_req = max(t_min,t , t_min,c), 필요시 제작 공차 계수(예: 최소두께
   보증이 없으면 t_eff = 0.9 t_nom) 반영
6. ALPEMA 5.11.4 제작 범위(0.15–0.7 mm, 피치 1.0–4.5 mm) 이내인지 확인
7. **파팅시트 최소두께**: 식 (7) → ALPEMA 5.11.1 범위(0.8–2.0 mm)와 비교

## 9. 예제 계산

### 예제 1 — 고압 탄화수소 스트림 (인장 지배)

입력: ΔP_t = 5.0 MPa(50 bar), T = 65 °C, p = 1.4 mm, h = 6.5 mm

- S(65 °C) = 22.8 MPa
- 식 (2): t ≥ 5.0×1.4 / (22.8+5.0) = **0.252 mm** → 선정 0.30 mm (ALPEMA 범위 내 ✓)
- 검산 식 (1): σ_t = 5.0×(1.4−0.30)/0.30 = 18.3 MPa ≤ 22.8 MPa ✓

### 예제 2 — 감압층 좌굴 검토 (압축)

입력: ΔP_c = 0.6 MPa, T = 93 °C, p = 2.0 mm, h = 9.5 mm, 선정 t = 0.40 mm, K = 0.7

- σ_c = 0.6×(2.0−0.40)/0.40 = 2.4 MPa
- 식 (4): σ_cr = π²×66 200×(0.40/(0.7×9.5))² / (12×(1−0.33²)) ≈ 221 MPa
- 허용: min(221/3, 22.6) = 22.6 MPa ≥ 2.4 MPa ✓ (통상 치수에서는 좌굴 여유 큼)

### 예제 3 — 파팅시트 연계

입력: 인접층 차압 w = 5.0 MPa, 양측 피치 1.4 mm(핀 t = 0.30 mm), T = 65 °C

- s = 1.4 − 0.30 = 1.10 mm
- 식 (7): t_ps ≥ 1.10×√(5.0/(3×22.8)) = **0.30 mm** → ALPEMA 표준 최소 0.8 mm 사용 시 여유 ✓

## 10. 한계 및 주의사항

- 본 식은 **정적 압력하중** 전용이다. 열응력·피로는 ALPEMA 8.1(운전 제한, 제조자
  피로평가)로 별도 관리한다.
- S(T) 테이블은 대표값이며 코드 연도판 확인이 필수다.
- 149 °C 초과 장기 운전은 크리프 영향으로 별도 검토가 필요하다.
- 실제 인증 설계는 ALPEMA 5.15.1.1(코드 당국 승인 계산법) 또는 5.15.1.2(파열시험)로
  확정한다. 파열시험 대비 본 계산의 안전계수 수준은 제조자 데이터와 비교 검증할 것.
- Serrated/Perforated 핀, 디스트리뷰터 핀, 헤더·노즐부는 범위 밖이다.
