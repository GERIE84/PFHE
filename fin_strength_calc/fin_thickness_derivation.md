# PFHE Plain 핀 적정두께 계산식 유도 (Rev.1)

**대상**: 브레이징 알루미늄 판형핀 열교환기(BAHX/PFHE) Plain 핀
**하중**: 층간 차압(ΔP) + 설계온도(T)의 영향
**허용응력 기준**: ASME Sec. VIII Div.1 (Sec. II-D 허용응력 S(T))
**핀 재질**: AL 3003-O (SB-209, 브레이징 후 완전 어닐링 'O' temper — ALPEMA 5.13)

> Rev.1: 6-에이전트 독립 검증에서 지적된 30건(주요 6건) 반영 — 압축 하중폭 정정(전피치),
> 비탄성 좌굴 천이(Johnson) 도입, 파팅시트 균형가압+핀 어긋남 하중케이스 추가,
> ALPEMA 5.6 인용 정정, 식(2)/(2') 차이 정량화, UG-50 스테이 계수 관계 명시 등.

---

## 1. 배경

ALPEMA Standard(2024) 5.15.1은 핀을 "압력하중을 견디는 구조 부재"로 규정하고, 핀의
최대 허용 설계압력을 **계산 또는 파열시험**으로 결정하도록 요구하지만(5.15.1.1/5.15.1.2),
압력용기 코드에는 핀 계산식이 수록되어 있지 않으며 구체적 방법은 제조자 고유 기술로
위임되어 있다. 본 문서는 공개된 역학 원리로부터 Plain 핀의 적정두께 계산식을 유도한다.

> **주의**: 본 유도식은 예비 설계(사양 검토·견적 검증·역산) 용도이다. 실제 제작용
> 설계는 ALPEMA 5.15.1.1에 따라 **코드 당국의 승인을 받은 제조자 계산법 또는
> 파열시험**으로 확정되어야 한다.

## 2. 범위와 가정

1. Plain(평판형) 핀만 대상으로 한다. Serrated/Perforated 핀은 유효 단면 감소
   계수(천공률 φ 등)를 추가로 반영해야 하며 본 문서 범위 밖이다.
2. **압력하중만** 고려한다. 열응력(과도 운전, 스트림 간 온도차)은 두께로 흡수하는
   것이 아니라 ALPEMA 8.1의 운전 제한(±1 °C/min 등)으로 관리하는 항목이다.
   온도의 영향은 재료 물성 S(T), E(T), Sy(T)의 저하로만 반영한다.
3. 탄성-비탄성(Johnson 천이) 해석 기반. 재료는 O-temper 최소 물성
   (3003-O: Su ≥ 96.5 MPa, Sy ≥ 34.5 MPa).
4. 크리프: 149 °C(≈300 °F) 이상에서는 S(T)가 시간 의존(크리프) 특성의 지배를 받기
   시작하며(§7.1, §10, ALPEMA Table 6-1 각주의 150 °C 크리프 언급과 정합),
   본 식은 S(T)를 통해 코드 범위 내에서만 이를 반영한다. 204 °C 초과는 범위 밖.
5. 피로, 부식 여유는 범위 밖(청정 극저온 서비스 전제).
6. 디스트리뷰터/헤더 영역은 제외하고 유효 전열부(finned region)의 반복 단위 셀만 본다.
7. 좌굴 검토 시 두 파팅시트 간 상대 수평변위(sway)는 사이드바와 브레이징 구속에
   의해 억제된다고 가정한다(§5.2).

## 3. 기하 정의와 기호

핀 채널 반복 단위 셀(피치 p) 단면:

```
   파팅시트(위)     ┌──────────────────────┐  ← t_ps
                    │   │        │         │
      핀 웹 →       │   │t       │    h    │
                    │   │        │         │
   파팅시트(아래)   └──────────────────────┘
                        |←  p  →|
```

| 기호 | 의미 | 단위 |
|---|---|---|
| p | 핀 피치 (= 1/n, n: 핀 밀도) | mm |
| t | 핀 두께 | mm |
| h | 핀 높이 (= 사이드바 높이) | mm |
| t_ps | 파팅시트 두께 | mm |
| ΔP_t | 핀 인장 유발 차압 (층 내부압 − 인접층 압력) | MPa |
| ΔP_c | 핀 압축 유발 차압 (인접층 압력 − 층 내부압) | MPa |
| S(T) | 설계온도 T에서의 ASME 허용응력 (3003-O) | MPa |
| Sy(T) | 설계온도 T에서의 최소 항복강도 (3003-O) | MPa |
| E(T) | 설계온도 T에서의 탄성계수 | MPa |
| ν | 포아송비 (알루미늄 0.33) | — |

### 설계 차압의 선정

인접 층의 압력은 신뢰할 수 있는 감압 방지 수단이 없는 한 **0(대기압)으로 가정**하는
것이 코드 관행과 일치한다. 근거:

- ALPEMA **5.6.1** 압력시험(수압 5.6.1.1 / 공압 5.6.1.2)은 "**각 챔버를 개별적으로**
  시험압력까지 가압"하므로 제작 단계에서 이미 인접층 0 상태의 전압력 하중이 구현된다.
- ALPEMA **5.6.2.1** 공기 누설시험은 "시험압력을 **한 챔버에만** 가하며, 통상 각 챔버의
  **설계압력**"이다.
- 운전 중에도 인접 스트림의 블록인·감압·무유동(no-flow) 상태가 발생할 수 있다
  (ALPEMA 5.16).

따라서 기본 설계 기준:

$$\Delta P_t = \text{해당 층의 설계압력(MAWP)}, \qquad \Delta P_c = \text{인접층 설계압력(자층 감압 가정)}$$

## 4. 파손모드 1 — 핀 인장 (기본 사양 결정식)

### 4.1 하중 경로

층 내부압 ΔP_t 는 위·아래 파팅시트를 **벌리는 방향**으로 작용하고, 이 분리력은 파팅
시트에 브레이징된 핀 웹의 **인장**으로 지지된다(ALPEMA 5.15.1: "These loads essentially
produce tensile stresses in the fins").

### 4.2 유도

단위 유동길이(1 mm)와 한 피치(p)를 갖는 단위 셀에서 위쪽 파팅시트에 대한 힘 평형:

- 유체가 시트를 미는 면적: 개구폭 × 단위길이 = (p − t) × 1
  (핀 풋(fin foot)이 브레이징된 폭 t에는 자층 유체압이 직접 작용하지 않음)
- 분리력: F = ΔP_t · (p − t)
- 이 힘을 받는 핀 웹 단면적: A = t × 1

핀 웹의 인장응력:

$$\sigma_t = \frac{\Delta P_t\,(p - t)}{t} \tag{1}$$

### 4.3 판정 기준과 두께식

1차 멤브레인 응력이므로 σ_t ≤ S(T) (ASME Div.1 UG-23 관행):

$$\frac{\Delta P_t\,(p-t)}{t} \le S(T)
\;\;\Longrightarrow\;\;
\boxed{\,t \;\ge\; \frac{\Delta P_t \; p}{S(T) + \Delta P_t}\,} \tag{2}$$

식 (2)가 **차압·온도·피치로부터 Plain 핀 최소두께를 주는 기본 사양 결정식**이다.
온도는 S(T)의 감소를 통해 두께 증가로 반영된다.

보수적 변형(핀 풋 폭에도 전압력이 작용한다고 가정, 총피치 기준):

$$t \ge \frac{\Delta P_t\, p}{S(T)} \tag{2'}$$

**두 식의 차이는 정확히** $t_{(2')}/t_{(2)} = 1 + \Delta P_t/S(T)$ 배이다. 즉
ΔP/S < 0.05 인 저압 조건에서만 수 % 이내이고, 예제 1 수준(ΔP = 5.0 MPa,
S = 22.8 MPa, ΔP/S ≈ 0.22)에서는 **약 22%**, 고온·고압(예: S = 11.0 MPa,
ΔP = 5.0 MPa)에서는 **약 45%** 벌어진다. 고차압 설계에서 핀 풋 브레이즈 실링의
건전성(풋 폭에 유체압 미작용 조건)을 별도로 확인할 수 없다면 식 (2')를 사용할 것.

### 4.4 ASME Div.1 스테이 규정과의 관계

핀은 기능상 평판을 지지하는 **인장 스테이**로, Div.1에서 가장 가까운 규정은
UG-50이다. 하중폭을 (p − t)로 취한 것은 UG-50(c)의 '전체 피치 면적에서 스테이
점유부 공제'와 정합한다. 다만 **UG-50(b)는 스테이 소요 단면적에 1.10 계수**(10%
추가)를 요구하므로, Div.1 스테이 관행을 온전히 따르려면:

$$t \;\ge\; \frac{1.10\,\Delta P_t\; p}{S(T) + 1.10\,\Delta P_t} \tag{2''}$$

본 문서의 기본식 (2)는 이 계수를 포함하지 않는다(핀은 UG-50의 적용 대상인 용접/
나사 스테이가 아니고 파열시험(5.15.1.2)과의 대비 검증을 전제로 하기 때문). 계수 적용이
필요하면 계산기의 `--stay-factor 1.10` 옵션을 사용한다.

### 4.5 브레이즈 조인트에 대한 참고

핀-파팅시트 접합부의 유효폭은 필렛 때문에 핀 웹 두께 t보다 크므로, 접합부가 건전하다면
웹 단면이 지배한다. 접합 품질(보이드율)의 영향은 파열시험(5.15.1.2)의 안전계수가
포괄하는 영역이며, 필요시 식 (1)의 t에 접합 효율 계수를 곱해 반영할 수 있다.

## 5. 파손모드 2 — 핀 압축·좌굴 (외압/인접 고압 조건)

### 5.1 하중

자층이 감압(진공, 블록인)되고 인접층이 가압 상태이면 순 차압 ΔP_c 가 두 파팅시트를
**모으는 방향**으로 작용하여 핀 웹이 압축된다.

**하중폭은 인장과 달리 전피치 p를 취한다.** 인장의 (p − t)는 '자층 유체압이 핀 풋
폭에는 직접 작용하지 않는다'는 논리였으나, 압축 하중은 **인접층에서 파팅시트를 통해**
전달되므로 자층 핀 풋이 압력을 차폐하지 못한다. 시트가 한 피치 폭에서 수집한 힘이
핀 풋 반력으로 모이므로:

$$\sigma_c = \frac{\Delta P_c\; p}{t} \tag{3}$$

(주: 이 파손모드는 '인접층 핀의 인장 하중경로가 무력화된 경우'를 가정한 포락 검토다.
건전한 주기적 코어 내부에서는 인접층 핀이 하중 대부분을 인장으로 부담하지만, 인접층
핀 손상·비대칭 배열·사이드바 인접부 등을 포괄하기 위해 전피치 기준으로 평가한다.)

### 5.2 좌굴 임계응력

Plain 핀 웹은 높이 h, 두께 t의 **긴 판 기둥**(유동 방향으로 연속)이다. 단위폭 판의
굽힘강성 D = E t³ / [12(1 − ν²)] 을 갖는 기둥의 탄성 임계응력:

$$\sigma_{cr,E} = \frac{\pi^2\,E(T)}{12\,(1-\nu^2)}\left(\frac{t}{K\,h}\right)^{2} \tag{4}$$

- **K: 유효길이계수 (무측방변위 전제).** 위·아래 가장자리는 파팅시트에 브레이징되어
  회전 구속을 받되 구속 강성은 시트 국부 굽힘·필렛 강성에 의존하므로 완전 고정으로
  볼 수 없다. 기본값 **K = 0.7은 고정-힌지 이론값**을 준용해 회전구속 불확실성을
  덮는 선택이다(완전 고정-고정 이론값 0.5, AISC 실무 설계값 0.65). 구속을 신뢰할 수
  없으면 K = 1.0(양단 힌지)을 사용한다.
- **sway 배제 근거(가정 7)**: 두 파팅시트의 상대 수평변위는 층 양측의 사이드바(전단
  격막)와 인접층들의 연속 브레이징 구조가 억제한다. 이 가정이 성립하지 않는 특수
  구조에서는 K ≥ 1.0 이 되어 위 값들이 비보수적일 수 있음에 유의.

### 5.3 비탄성 천이 (Johnson 포물선)

3003-O의 항복강도(Sy ≈ 34.5 MPa)가 낮아, 통상 치수의 핀에서는 탄성 임계응력
σ_cr,E 가 항복점을 초과하는 경우가 많다. 이 구간에서 탄성식은 허구적 수치이며
접선계수 효과로 실제 임계응력이 저하되므로, **Johnson 포물선 천이**를 적용한다:

$$\sigma_{cr} =
\begin{cases}
\sigma_{cr,E} & \sigma_{cr,E} \le S_y/2 \\
S_y\left(1 - \dfrac{S_y}{4\,\sigma_{cr,E}}\right) & \sigma_{cr,E} > S_y/2
\end{cases} \tag{4'}$$

σ_cr 는 Sy를 넘지 않으며, 세장할수록 탄성식에 연속적으로 접속된다. (참고: ASME
Div.1 UG-28의 B차트도 재료별 접선계수 곡선으로 동일한 비탄성 영역을 처리한다 —
순수 탄성식 + DF만으로는 천이역에서 목표 설계계수가 성립하지 않는다.)

### 5.4 판정 기준

ASME Div.1 외압 좌굴 설계 철학(UG-28, 설계계수 ≈ 3)을 준용하여:

$$\sigma_c \;\le\; \sigma_{c,allow} = \min\!\left(\frac{\sigma_{cr}}{3},\; S(T)\right) \tag{5}$$

- 짧고 두꺼운(stocky) 핀에서는 σ_cr → Sy 이므로 σ_c,allow → Sy/3 이 되는데, 이는
  순수 압축 항복 관점(허용 ≈ ⅔Sy)보다 보수적이다. 압축 케이스는 드문 이탈 조건의
  포락 검토이므로 보수성을 수용한다.
- 식 (3)과 (5)를 결합하면 t에 대한 비선형식이 되므로 수치해(이분법)로 최소두께를
  구한다(첨부 계산기). σ_c 는 t에 단조감소, σ_c,allow 는 단조증가이므로 근은 유일하다.

## 6. 파손모드 3 — 파팅시트 굽힘 연계

### 6.1 하중케이스 A — 층간 차압(단독가압 포락)

파팅시트는 핀 풋들을 지지점으로 하는 **연속 스트립 보**로 거동한다. 시트 양면의 층간
순 차압 w = |P_A − P_B| 가 등분포 하중으로 작용하고, 지지 간격은 **양면 중 성긴 쪽
피치** 기준의 순 스팬을 취한다:

$$s = \max(p_A,\,p_B) - t_{fin}$$

여기서 t_fin 은 **성긴 피치 쪽 층의 최소 보증 핀 두께**(공차 반영 후)이며, 가장
보수적으로는 풋 폭 공제를 생략하고 s = max(p_A, p_B) 를 쓸 수 있다.

등스팬·등하중 내부 스팬의 지점 모멘트: M_A = w s²/12.

> 단서: 사이드바 인접 **단부 스팬**은 단부 고정도가 완전하지 않으면 첫 내부 지점
> 모멘트가 최대 약 w s²/10 까지 증가한다(모멘트 +20%, 소요두께 약 +10%). 사이드바
> 브레이즈의 회전구속으로 실무 영향은 제한적이나, 단부 스팬이 지배하는 좁은 코어에서는
> 계수 1/10 채택을 검토할 것.

### 6.2 하중케이스 B — 균형가압 + 핀 풋 어긋남 (교번 하중)

양면 층이 **동시에 가압**되면(P_A ≈ P_B) w ≈ 0이라 케이스 A는 소요두께 0을 예측
하지만, 양면 핀 풋 위치가 어긋난(staggered) 경우 시트에는 양면 핀들의 **교번 집중
인장 풀**(±T, T = P·(p − t), 간격 ≈ p/2)이 작용하여 피크 모멘트가 발생한다:

$$M_B \approx \frac{P_{min}\,(\bar p - t_{fin})\,\bar p}{8}, \qquad
P_{min} = \min(P_A, P_B),\;\; \bar p = \max(p_A, p_B)$$

이 케이스는 '인접층 0 가정'(§3) 포락이 **커버하지 못하며**, 예제 3 조건에서 M_B 는
M_A 의 약 1.9배에 달한다. 따라서 설계 모멘트는 두 케이스의 합성으로 포락한다:

$$M_d = \frac{w\,s^2}{12} + \frac{P_{min}\,(\bar p - t_{fin})\,\bar p}{8} \tag{6}$$

(한쪽이 감압 상태면 P_min = 0 이 되어 케이스 A로 환원된다. 양면 핀 풋이 정렬
(aligned)된 제작이 보증되면 두 번째 항은 소거 가능하나, 통상 정렬은 보증되지 않는다.)

### 6.3 판정 기준과 두께식

1차 굽힘응력 허용치 1.5 S(T) 적용(ASME 관행), σ_b = 6 M_d / t_ps²:

$$\frac{6\,M_d}{t_{ps}^2} \le 1.5\,S(T)
\;\;\Longrightarrow\;\;
\boxed{\, t_{ps} \;\ge\; \sqrt{\frac{4\,M_d}{S(T)}}\,} \tag{7}$$

케이스 A 단독(P_min = 0)이면 종전 형태 $t_{ps} \ge s\sqrt{w/(3S)}$ 로 환원된다.

**연계 의미**: 핀 피치를 키우면 식 (2)의 핀 두께와 식 (7)의 파팅시트 두께가 동시에
증가한다. 참고로 ALPEMA 5.15.2가 규정하는 파팅시트 응력은 **사이드바 압력하중
경로의 인장(멤브레인) 응력**으로 본 절의 핀 풋 지지 굽힘 모델과는 하중경로가 다르다
— 본 절은 이에 **추가되는 국부 굽힘 검토**이다.

## 8. 계산 절차 요약

1. 입력: ΔP_t, ΔP_c, 설계온도 T, 자층 핀 피치 p, (파팅시트용) 인접층 피치 p_adj,
   핀 높이 h, 층간 차압 w, 균형가압 시 낮은 쪽 압력 P_min
2. S(T), Sy(T), E(T) 보간 (T ≤ 204 °C 확인)
3. **핀 인장 최소두께**: 식 (2) (필요시 스테이 계수 1.10 반영 식 (2'')) → t_min,t
4. **핀 좌굴 최소두께**: 식 (3)+(4')+(5) 수치해 → t_min,c
5. 유효 요구두께 t_req = max(t_min,t , t_min,c). 최소두께 보증이 없으면 공차 계수
   반영: 공칭두께 t_nom ≥ t_req / (공차계수). **합부 검증도 유효두께
   (공차계수 × 공칭) 기준으로 수행한다.**
6. ALPEMA 5.11.4 제작 범위(두께 0.15–0.7 mm, 피치 1.0–4.5 mm) 이내인지 확인
7. **파팅시트 최소두께**: 스팬 s = max(p, p_adj) − t_fin,유효, 식 (6)~(7) →
   ALPEMA 5.11.1 범위(0.8–2.0 mm)와 비교

## 9. 예제 계산

### 예제 1 — 고압 탄화수소 스트림 (인장 지배)

입력: ΔP_t = 5.0 MPa(50 bar), T = 65 °C, p = 1.4 mm, h = 6.5 mm

- S(65 °C) = 22.8 MPa
- 식 (2): t ≥ 5.0×1.4 / (22.8+5.0) = **0.252 mm** → 선정 0.30 mm (ALPEMA 범위 내 ✓)
- 검산 식 (1): σ_t = 5.0×(1.4−0.30)/0.30 = 18.3 MPa ≤ 22.8 MPa ✓
- (참고) 보수식 (2'): t ≥ 5.0×1.4/22.8 = 0.307 mm — 식 (2) 대비 +22%

### 예제 2 — 감압층 좌굴 검토 (압축)

입력: ΔP_c = 0.6 MPa, T = 93 °C, p = 2.0 mm, h = 9.5 mm, 선정 t = 0.40 mm, K = 0.7

- 식 (3): σ_c = 0.6×2.0/0.40 = **3.0 MPa**
- 식 (4): σ_cr,E = π²×66 200×(0.40/(0.7×9.5))² / (12×(1−0.33²)) ≈ 221 MPa
- Sy(93 °C) = 33.1 MPa, σ_cr,E > Sy/2 → 식 (4'): σ_cr = 33.1×(1 − 33.1/(4×221)) ≈ **31.9 MPa**
- 식 (5): 허용 = min(31.9/3, 22.6) = **10.6 MPa** ≥ 3.0 MPa ✓

### 예제 3 — 파팅시트 연계

입력: 양측 피치 1.4 mm(핀 t = 0.30 mm), T = 65 °C → s = 1.10 mm

- **케이스 A** (단독가압: P_A = 5.0, P_B = 0 → w = 5.0, P_min = 0):
  M_d = 5.0×1.10²/12 = 0.504 N·mm/mm → t_ps ≥ √(4×0.504/22.8) = **0.297 mm**
- **케이스 B** (균형가압: P_A = P_B = 5.0 → w = 0, P_min = 5.0):
  M_d = 5.0×1.10×1.4/8 = 0.963 N·mm/mm → t_ps ≥ √(4×0.963/22.8) = **0.411 mm**
- 지배 케이스 B: t_ps ≥ 0.411 mm → ALPEMA 표준 최소 0.8 mm 사용 시 여유 ✓
  (케이스 B가 A의 약 1.9배 모멘트 — 균형가압+어긋남이 지배할 수 있음)

## 10. 한계 및 주의사항

- 본 식은 **정적 압력하중** 전용이다. 열응력·피로는 ALPEMA 8.1(운전 제한, 제조자
  피로평가)로 별도 관리한다.
- S(T)/Sy(T)/E(T) 테이블은 대표값이며 코드 연도판 확인이 필수다.
- 149 °C 초과 장기 운전은 크리프 영향으로 별도 검토가 필요하다(가정 4).
- 좌굴 K값은 sway 억제(가정 7)를 전제하며, 특수 구조에서는 K ≥ 1.0 검토.
- 파팅시트 단부 스팬(사이드바 인접)은 1/12 계수가 비보수적일 수 있다(§6.1 단서).
- 파팅시트 식 (6)의 교번 하중 항은 근사(집중 풀 간격 ≈ p/2 가정)이며, 양면 피치가
  크게 다르거나 특수 배열이면 별도 상세해석을 권한다.
- 실제 인증 설계는 ALPEMA 5.15.1.1(코드 당국 승인 계산법) 또는 5.15.1.2(파열시험)로
  확정한다. 파열시험 대비 본 계산의 안전계수 수준은 제조자 데이터와 비교 검증할 것.
- Serrated/Perforated 핀, 디스트리뷰터 핀, 헤더·노즐부는 범위 밖이다.
